# Variables en Python

## Qué es una variable
Una variable es un nombre que guarda un valor en la memoria. Se crea con el signo igual: `edad = 15`. El nombre va a la izquierda y el valor a la derecha. Se puede pensar como una caja con etiqueta.

## Tipos de datos básicos
Los tipos más comunes son int (enteros como 7), float (decimales como 3.5), str (texto como "hola") y bool (True o False). Python detecta el tipo solo. Con `type(x)` se consulta.

## Reglas para nombres
Los nombres no pueden empezar con número ni llevar espacios. Se recomienda usar minúsculas y guion bajo: `nombre_alumno`. Python distingue mayúsculas de minúsculas.
