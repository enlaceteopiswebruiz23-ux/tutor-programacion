# Funciones en Python

## Definir una función
Una función es un bloque de código con nombre que se puede reutilizar. Se define con def: `def saludar():` y debajo el cuerpo con sangría. Se llama escribiendo `saludar()`.

## Parámetros y return
Los parámetros son los datos que recibe la función: `def sumar(a, b):`. Al llamarla se pasan argumentos: `sumar(2, 3)`. `return` devuelve un resultado: `return a + b`. Sin return, la función devuelve None.

## Por qué usar funciones
Evitan repetir código, hacen el programa más ordenado y fáciles de probar. Conviene que cada función haga una sola cosa y tenga un nombre claro.
