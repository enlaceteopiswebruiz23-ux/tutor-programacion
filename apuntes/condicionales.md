# Condicionales en Python

## if
Un condicional ejecuta código solo si una condición es verdadera. Ejemplo: `if edad >= 18:` y debajo, con sangría de 4 espacios, lo que se hace. Los dos puntos son obligatorios.

## else y elif
`else` se ejecuta cuando la condición del if es falsa. `elif` permite revisar otra condición si la anterior falló. Solo se ejecuta el primer bloque que cumpla.

## Operadores de comparación
Se usan `==` (igual), `!=` (distinto), `>`, `<`, `>=`, `<=`. Para combinar condiciones se usan `and`, `or` y `not`. No confundir `=` (asignar) con `==` (comparar).
