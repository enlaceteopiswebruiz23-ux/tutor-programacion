# Bucles en Python

## for
El bucle for recorre una secuencia. Para repetir algo 5 veces: `for i in range(5):` y debajo el código con sangría. `range(5)` genera 0, 1, 2, 3, 4.

## while
El bucle while repite mientras una condición sea verdadera: `while contador < 5:`. Hay que cambiar la variable dentro del bucle, o se vuelve infinito.

## break y continue
`break` sale del bucle de inmediato. `continue` salta a la siguiente repetición. Usa for cuando sabes cuántas veces repetir y while cuando depende de una condición.
